Reference

Formatting Help

Markdown is a lightweight way to format text using simple symbols instead of a complex editor. In TavernKeeper, it lets you structure notes, create headings and lists, link to World Atlas pages, and embed supported images or video directly into the text body.

Headings

Section Titles

# Heading One
## Heading Two
### Heading Three

Use headings to break long notes, lore drops, and handouts into readable sections.

Emphasis

Bold And Italic

**bold text**
_italic text_

Use bold for key clues or warnings, and italic for emphasis, whispers, or flavor text.

Lists

Bullets And Numbers

- First bullet
- Second bullet

1. First step
2. Second step

Great for quest steps, treasure lists, rumors, or DM prep checklists.

Quotes

Blockquotes

> A voice from the tide answered
> in a language older than bells.

Useful for letters, prop text, spoken omens, or excerpts from ancient records.

Rules

Divider Lines

---
***

Add a visual break between scenes, sections, or chunks of reference material.

Links

External Links

[Map Reference](https://example.com/map)

Link out to documents, references, maps, or other web resources.

World Atlas

Entry Crosslinks

[[Aetheria, Realm of the Maelstrom]]

The name must match an existing World Atlas entry exactly. If it matches, TavernKeeper turns it into a link.

Images

Inline Image Embeds

[https://example.com/image.png]

Put the image URL on its own line for the cleanest result. Supported image file URLs render inline.

Video

Inline Video Embeds

[https://example.com/video.mp4]
[https://youtu.be/example]
[https://vimeo.com/example]

Direct video files and supported platforms such as YouTube or Vimeo can embed inline. Other sites may fall back to a normal link if the host blocks embedding.
